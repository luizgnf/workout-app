TREINO ABC — PWA

PUBLICAR GRÁTIS NO GITHUB PAGES (pelo celular)
1. Entre em github.com pelo Safari e faça login/crie uma conta.
2. Crie um repositório novo, por exemplo: treino-abc. Pode ser público.
3. Envie para a raiz do repositório estes 5 arquivos:
   index.html
   manifest.webmanifest
   sw.js
   icon-192.png
   icon-512.png
4. No repositório, abra Settings > Pages.
5. Em Build and deployment, escolha Deploy from a branch.
6. Branch: main; pasta: /(root); Save.
7. O GitHub mostrará a URL do site após a publicação.
8. Abra essa URL no SAFARI do iPhone.
9. Compartilhar > Adicionar à Tela de Início.

IMPORTANTE SOBRE OS DADOS
- Cargas, repetições e histórico ficam no armazenamento local do navegador/PWA.
- Fechar e reabrir o app mantém o progresso.
- Use Dados > Exportar backup periodicamente.
- Limpar dados do site, remover armazenamento do Safari ou trocar de aparelho pode apagar o banco local.
- O backup JSON pode ser importado pelo próprio app.
